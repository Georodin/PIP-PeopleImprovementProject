# Preview sources

The supplied screenshot of the layered base is from Zombies Aren't Real, by Jogamedev / Octavia Blue. It is used to illustrate the intended first feature. Game visuals remain the property of their owners.

Typography and layout reference: Georodin's DDI `Photoshop/preview.psd`, inspected locally in Photoshop. Reference canvas 1276 x 716, large stacked initials in Catesque-Medium, smaller word endings in Catesque-Light, author credit in Roboto-Light. The new PSD uses available Arial fonts and contains separate editable text, background, grid, frame, status and screenshot layers.

No mining stock photo, Envato illustration, concrete stock texture, or RimWorld expansion mark from the reference PSD is included. The new background and layout elements are original. Font files are not bundled. `Photoshop/Create-Preview.cjs` regenerates the PSD and its flattened PNG. Photoshop may request a text-layer update on first opening, because the PSD is authored with ag-psd.
